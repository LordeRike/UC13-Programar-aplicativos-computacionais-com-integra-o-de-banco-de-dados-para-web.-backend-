Atividade Funções - Validação de Senha

Crie um formulário onde o usuário digite uma senha. Essa senha deve ser enviada para o php e através de uma função validar se a senha é forte.
Critérios para a senha ser considerada forte.
Ter pelo menos 8 caracteres
Conter pelo menos uma letra maiúscula
Conter pelo menos um número.
A função deve retornar true se for válida e false caso contrário.
